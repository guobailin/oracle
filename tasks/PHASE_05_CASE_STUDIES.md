# Phase 05 — Difficult inscription case studies

**Window:** Weeks 9–10  
**Goal:** Apply the validated workflow to a small number of genuinely difficult, evidence-rich cases.  
**Status:** TODO

## Work packages

### T5.1 — Select 5–10 research cases
- **Priority:** P2 | **Depends on:** Phase 04
- **Steps:** Rank candidate cases by scholarly importance, unresolved status, image availability, contextual evidence, rights, and feasibility.
- **Deliverable:** Case selection memo.
- **Acceptance:** Each selected case has a clear research question and a reason it is suitable for this study.

### T5.2 — Assemble documentary evidence
- **Priority:** P2 | **Depends on:** T5.1
- **Steps:** Locate published transcriptions, rubbings/photos, catalog records, parallel inscriptions, and relevant scholarly arguments.
- **Deliverable:** Cited evidence dossier per case.
- **Acceptance:** Sources are independently verifiable; conflicting scholarship is represented fairly.

### T5.3 — Retrieve paleographic candidates
- **Priority:** P2 | **Depends on:** T4.2, T5.2
- **Steps:** Run visual retrieval against documented candidate collections; inspect top results; record why candidates match or fail.
- **Deliverable:** Candidate ranking and comparison sheet.
- **Acceptance:** Similarity scores are treated as retrieval aids, not proof of identity or reading.

### T5.4 — Analyze inscription context
- **Priority:** P2 | **Depends on:** T4.4, T5.2
- **Steps:** Examine syntax, formulae, parallel texts, archaeological context, and relevant historical constraints with scholarly sources.
- **Deliverable:** Context analysis with explicit alternative interpretations.
- **Acceptance:** Every interpretive step is supported or labeled as conjecture; plausible alternatives are not omitted.

### T5.5 — Cross-check models and specialists
- **Priority:** P2 | **Depends on:** T5.3, T5.4
- **Steps:** Compare distinct model families and human assessments; blind reviewers to model identity where practical; log disagreement.
- **Deliverable:** Comparison report and review log.
- **Acceptance:** Model voting is not used as a substitute for evidence; model outputs are evaluated against the same evidence packet.

### T5.6 — Conduct adversarial and counter-evidence review
- **Priority:** P2 | **Depends on:** T5.3–T5.5
- **Steps:** Search for evidence that would falsify each candidate; test alternative graph forms and readings; document unresolved ambiguity.
- **Deliverable:** Case conclusion with supporting and opposing evidence.
- **Acceptance:** Each case ends with a calibrated status (e.g. supported, plausible, unresolved, rejected), not an overconfident forced translation.

## Case dossier minimum contents

- Stable artifact/inscription identifiers and source provenance
- Original image reference and permitted-use note
- Graph segmentation and condition/damage notes
- Published readings and citations
- Candidate forms and visual comparisons
- Contextual and linguistic evidence
- AI outputs with model/version/prompt metadata
- Counter-evidence and alternative hypotheses
- Reviewer comments and current conclusion

## Phase exit gate
Each case dossier is independently reviewable and makes clear which conclusions are established, disputed, speculative, or still unknown.
